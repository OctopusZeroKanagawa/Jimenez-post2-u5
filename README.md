# Catálogo Web con Carrito de Compras

Aplicación web desarrollada en Java utilizando Servlets, JSP, JSTL y gestión de sesiones HTTP. El proyecto implementa un catálogo de productos con funcionalidades de búsqueda, filtrado por categorías y un carrito de compras almacenado en sesión.
Este laboratorio fue desarrollado como parte de la Unidad 5 de Programación Web.

## Tecnologías utilizadas

- Java 17
- Jakarta Servlet API 6.0
- JSP
- JSTL
- Apache Tomcat 10.1
- Maven
- IntelliJ IDEA

### Pasos

1. Clonar el repositorio:

2. Abrir el proyecto en IntelliJ IDEA.

3. Configurar Apache Tomcat 10.

4. Ejecutar el artifact

5. Acceder desde el navegador: http://localhost:8080/catalogo-web/catalogo
